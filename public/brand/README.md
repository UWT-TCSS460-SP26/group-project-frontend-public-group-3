# Brand assets

Drop your PNG files here with these exact names:

| File | Purpose | Recommended size |
|------|---------|------------------|
| `logo.png` | Header logo (top of every page) | ~120–200px tall, transparent background if possible |
| `favicon.png` | Browser tab icon | 32×32 or 48×48, square |

Files are served at:

- `/brand/logo.png`
- `/brand/favicon.png`

PNG format is fine — no conversion needed.
